# Keyboard shortcuts

| Shortcut     | Does                        |
| ------------ | --------------------------- |
| ⇧⌘P          | Command palette             |
| ⌘N           | New document                |
| ⌘O           | Open                        |
| ⇧⌘O          | Open Recent                 |
| ⌘S           | Save                        |
| ⇧⌘S          | Save As                     |
| ⌘E           | Export as PDF               |
| ⇧⌘E          | Export as Word              |
| ⌥⌘E          | Export as Web Page          |
| ⇧⌘Y          | Sync files                  |
| ⌘,           | Settings                    |
| ⌘Z / ⇧⌘Z     | Undo / redo                 |
| ⌘F           | Find                        |
| ⌘/           | Show or hide the Markdown   |
| ⌘= / ⌘- / ⌘0 | Zoom in / out / actual size |
| ⌘B           | Bold                        |
| ⌘I           | Italic                      |
| ⇧⌘X          | Strikethrough               |
| ⇧⌘H          | Highlight                   |
| ⌥⌘1 – ⌥⌘4    | Heading 1 – 4               |
| `@`          | Suggest a cross-reference   |
| Tab          | Nest a list item            |
